Videos › Essentials › Get a video
Get a video Public

Returns information about a specific video from the authenticated user's account or any publicly available video.

Try it out
GET https://api.vimeo.com /videos/{video_id}
Required scopes
public private
Your access token must include at least one of these scopes.

Path parameters

Parameter Type Description
video_id
 number The ID of the video.

Query parameters

Parameter Type Description
fields
 string A comma-separated list of fields to include in the response. Reduces payload size.
Example: uri,name,description,duration,privacy

Responses

StatusDescription
200The video was returned.
401The access token is invalid or missing the required scope.
404No such video exists, or the requester doesn't have access to it.
{ "uri": "/videos/123456789", "name": "My Video Title", "description": "A description of the video.", "type": "video", "link": "https://vimeo.com/123456789", "duration": 142, "width": 1920, "height": 1080, "privacy": { "view": "anybody", "embed": "public" }, "status": "available", "created_time": "2024-01-15T10:30:00+00:00" }
Videos › Essentials › Edit a video
Edit a video Public

Edits the specified video. The authenticated user must be the owner or have admin access to the video.

Try it out
PATCH https://api.vimeo.com /videos/{video_id}
Required scope
edit
Your access token must include this scope.

Path parameters

ParameterTypeDescription
video_id
 number The ID of the video.

Body parameters

application/vnd.vimeo.video+json
ParameterTypeDescription
name
 string The new title for the video.
description
 string The new description for the video.
privacy.view
 string Who can view the video.
Values: anybody nobody password disable unlisted users
privacy.embed
 string The embed privacy setting.
Values: public private whitelist
review_page.active
 boolean Whether the review page is enabled for this video.

Responses

StatusDescription
200The video was edited.
400A parameter is invalid or missing.
403The authenticated user can't edit this video.
404No such video exists.
{ "name": "Updated Title", "description": "Updated description.", "privacy": { "view": "unlisted" }, "review_page": { "active": true } }
Lead Capture › Registrants › Add registrants
Add registrants Internal

Adds one or more registrants to a lead-capture resource. Supports bulk registration for webinars and live events.

Try it out
PUT https://api.vimeo.com /lead_capture/{resource_type}/{resource_id}/registrants
Required scopes
edit create
Your access token must include both of these scopes.

Path parameters

ParameterTypeDescription
resource_type
 string The type of resource to add registrants to.
Values: event webinar
resource_id
 number The ID of the event or webinar.

Query parameters

ParameterTypeDescription
send_email PRIVATE
 boolean When true, sends a confirmation email to each registrant after registration.
override_capacity PRIVATE
 boolean When true, allows registration past the event's attendee capacity limit.

Body parameters

application/vnd.vimeo.lead_capture.registrant+json
ParameterTypeDescription
registrants
 array Array of registrant objects to add.
registrants[].email
 string The registrant's email address.
registrants[].first_name
 string The registrant's first name.
registrants[].last_name
 string The registrant's last name.
registrants[].custom_fields PRIVATE
 object Key-value map of custom field values for this registrant.

Responses

StatusDescription
200Registrants were added successfully.
400A required parameter is missing or invalid.
403The authenticated user doesn't have permission to add registrants to this resource.
404The specified resource doesn't exist.
422One or more registrant objects failed validation (e.g., invalid email format).
{ "registrants": [ { "email": "jane.doe@example.com", "first_name": "Jane", "last_name": "Doe" } ] }
